# 인터뷰·공개 TC 보충 규칙

## L-03 배송지 변경 요청

- 고객이 배송지 변경을 요청하면 먼저 대상 주문번호를 받고, 그 주문이 변경 대상이 맞는지 확인한다.
- `GET /api/shipments?order_no=<주문번호>`로 해당 주문의 배송 건만 조회한다.
- 배송 검색 결과가 빈 배열이면 아직 집하 전이므로 배송지 변경 요청을 접수할 수 있다.
- 배송이 이미 시작됐다면 배송지 변경을 접수하지 않는다.
- 시 단위의 주소만으로는 부족하며, 시·군·구, 도로명 또는 번지, 해당하는 동·호수까지 상세주소를 받아 확인한다.
- 확인된 주문번호와 상세주소로 `POST /api/orders/{order_no}/address-change-requests`를 호출한다.
- API 성공은 변경 완료가 아니라 변경 요청 접수이다.
